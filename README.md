# PhysSim Studio

Интерактивный 3D-физический симулятор и редактор объектов на **Unity (C#)** — «продвинутый Blender»:
создание примитивов и импорт OBJ/FBX, редактирование в рантайме, база из 100+ материалов и сплавов
с реальными физическими свойствами (плотность, трение, аэродинамика), симуляция с паузой/шагом.

## Документация

- [ARCHITECTURE.md](ARCHITECTURE.md) — архитектура проекта: модули, менеджеры, физическая модель, дорожная карта.

## Быстрый старт

1. Установите **Unity 2022.3 LTS** (или Unity 6) с модулем Windows/Mac.
2. Откройте репозиторий как проект в Unity Hub (пакеты подтянутся из `Packages/manifest.json`).
3. Откройте сцену `Assets/_Project/Scenes/Main.unity` (создаётся в вехе M0).
