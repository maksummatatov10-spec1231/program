# PhysSim Studio

Интерактивный 3D-физический симулятор и редактор объектов на **Unity (C#)** — «продвинутый Blender»:
примитивы и импорт OBJ, редактирование в рантайме (гизмо Move/Rotate/Scale, инспектор), база из
**121 материала и сплава** с реальными физическими свойствами (плотность → масса, трение, упругость,
аэродинамика), симуляция с паузой/шагом, сохранение/загрузка сцен, экспорт OBJ, undo/redo.

## Быстрый старт (до EXE — 3 шага)

1. Установите **Unity 2022.3 LTS** через [Unity Hub](https://unity.com/download) (любой патч 2022.3).
2. В Unity Hub: *Add → Select from disk* → укажите папку проекта → откройте. Дождитесь импорта.
3. Меню **PhysSim → Собрать EXE (Windows x64)** → готовый билд появится в `Build/Windows/PhysSimStudio.exe`.

Либо просто нажмите **Play** в редакторе — программа работает сразу, никаких ассетов создавать не нужно
(сцена, UI, камера, земля и база материалов собираются кодом при старте).

Подробности: [docs/BUILD_RU.md](docs/BUILD_RU.md) (включая сборку установщика `.exe` через Inno Setup).

## Управление

| Клавиша | Действие |
|---|---|
| ЛКМ | выбрать объект (Shift — добавить) |
| ПКМ / СКМ / колесо | орбита / панорама / зум камеры |
| **W / E / R** | гизмо: перемещение / вращение / масштаб |
| **P** | пауза/пуск симуляции, **B** — вкл/выкл физику объекта |
| **Ctrl+Z / Ctrl+Y** | undo / redo |
| **Del / Ctrl+D / F** | удалить / дублировать / кадрировать |

## Статус

Реализованы вехи M0–M5 из [ARCHITECTURE.md](ARCHITECTURE.md): каркас, редактор объектов, симуляция,
материалы (121 шт.), импорт/экспорт, гизмо. FBX-импорт — заглушка (требуется нативный плагин AssimpNet,
см. [docs/BUILD_RU.md](docs/BUILD_RU.md)); OBJ работает полностью.
